# Материалы учебной демонстрации

Не производственная система, не оптимизатор и не результаты заводского пилота. Кандидат: `d3f3d9c2c1e9f12c3345b6112327e2998bf8066f5518e2e635233c98171cea3f`.

- [Паспорт HTML](scenario-passport.html) — автономная русская сводка всех этапов.
- [Паспорт PDF](scenario-passport.pdf).
- [Презентация PDF](presentation.pdf) — печать существующего public/slides.html.
- [Полный JSON](scenario-lineage.json) — входы, переходы, все версии и полные машинные/материальные/кадровые отчёты без округления.
- [Резервная последовательность](screenshots/index.html) — 8 реальных кадров, включая 390 px.
- [Проверки экспорта](export-checks.json) — идентичность UI/API, сеть, axe, хеши, страницы PDF и ограничения.

После завершения приёмочного браузерного прогона в корне репозитория: `node tools/export-deliverables.mjs --run --evidence`. Нужны уже установленные зависимости и Chromium. Используется только собственный 127.0.0.1:4183: при занятом порте инструмент завершится ошибкой, без повторного использования чужого сервера. UI собирается один раз в памяти; dist и 4173 не изменяются. JSON/HTML можно читать отдельно; для всех относительных ссылок откройте папку через локальный HTTP-сервер. Для повторной проверки хешей: `node tools/manifest.mjs source`, `node tools/manifest.mjs delivery` (вывод сохранять вне artifacts, например в evidence).

Отчёты до исправления физического конфликта — контрфактические проекции, а не фактическое производство. Сроки могут иметь честные дефициты. Полный интервальный журнал в JSON, не на каждой печатной странице. Независимые продуктовые тесты и проверка PDF отдельным просмотрщиком не заменяются этим инструментом. Фразы исходных слайдов/приложения о ещё не созданных PDF/скриншотах относятся к состоянию до отдельного экспорта; фактический состав этой папки описан здесь.
