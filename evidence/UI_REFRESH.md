# Обновление интерфейса — проверка

Контракт: [UI refresh v1](../docs/UI_REFRESH_SPEC.md). База: `c7dba63`.
Это отдельное обновление интерфейса: расчётное ядро, зависимости и прежние тесты не изменены.
Старые `package.json` в этой папке и `reviews/FINAL.md` описывают предыдущий релиз.

## Изменения

- Нейтральная графитовая тёмная тема и синие акценты; светлый рабочий экран сохранён.
- Выбор темы применяется до запуска приложения, сохраняется при доступном storage;
  при отказе storage интерфейс и переключатель продолжают работать.
- Боковая панель отслеживает клики, прокрутку, прямые ссылки и историю браузера;
  обработчики очищаются при повторном создании интерфейса.
- Видимый текст основного экрана: **1701 → 1435 слов, −15,6%**. Подсчёт по
  `main.innerText.trim().split(/\s+/)`; таблицы и расчётные данные не скрыты.
- Презентация: нейтральная светлая палитра, сокращённые пояснения, десять слайдов.

## Исправленные ошибки проверок

- Исходная тема сбрасывалась при перезагрузке; у навигации не было текущего состояния.
- Первый E2E: 60/63 PASS, три одинаковых отказа по недостаточному сокращению текста
  (1554 слова при пороге 1445). Текст сокращён до 1435, порог не ослаблялся.
  [Исходные наблюдения](ui-refresh-initial-check.json).
- Один повторный полный прогон прерван; он не используется как доказательство PASS.
- На странице слайдов устранён запрос отсутствующего favicon.ico.
- Axe нашёл серьёзное несоответствие названий девяти ссылок слайдов; после исправления
  повторная проверка на двух ширинах дала ноль нарушений.
- Один экспорт завершился ошибкой записи `evidence/export-checks.json` в Windows
  после генерации материалов. Повтор команды полностью прошёл; причина сбоя записи
  не установлена и не объявляется ошибкой приложения.
